Project Anupam

A Marketplace Built for Student Entrepreneurs

Project Anupam is a creator-focused e-commerce platform built with JDMC's Incubation Program, giving young women entrepreneurs a place to showcase and sell their products online.

Visit Project Anupam →
🎓 Built with JDMC Incubation Program 🛍 Live Marketplace
The Problem

From creativity to commerce

Talented students had the skills to create products like handmade jewelry, home décor, crochet, and art — but no platform to showcase and sell their work. NorthernGeek partnered with Janki Devi Memorial College's (JDMC) Incubation Program to build that platform.

What We Built

A complete marketplace platform

From storefront to admin approvals — everything creators and customers need in one place.

Online Storefront

A complete marketplace storefront for showcasing creator products.

Creator Profiles

Dedicated profiles that allow creators to present their work.

Become a Creator

An onboarding flow for new creators joining the marketplace.

Order Tracking

Customers can track their orders through the platform.

Secure Login

Authentication for platform users.

COD Checkout

Cash-on-delivery checkout support.

Admin Dashboard

Centralized management for products, orders and approvals.

Responsive Experience

Designed to work across desktop and mobile devices.

Partnership

Built with JDMC's Incubation Program

Project Anupam was created in collaboration with Janki Devi Memorial College's (JDMC) Incubation Program, which supports student entrepreneurs.

NorthernGeek designed and built the digital platform that brings the marketplace experience together — from storefront and creator onboarding to orders, approvals and administration.
